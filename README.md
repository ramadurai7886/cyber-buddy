## 📌 About Cyber Buddy

**Cyber Buddy** is a specialized, trauma-informed digital first-aid application created for women in India facing online gender-based violence, cyber blackmail, non-consensual image abuse (NCII), morphing/deepfakes, impersonation, and stalking.

Unlike conventional reporting portals, Cyber Buddy combines **immediate technical assistance**, **evidence preservation**, **free 24/7 government psychological counseling**, **formal police complaint generation**, and **anti-surveillance discretion** in one accessible, client-side safe haven.

## 🚀 Application Workflows

### 1. 🚨 Workflow 1: Emergency Mode (No Login Required)

Designed for victims in active panic who need immediate safety guidance:

1. **Step 1: Privacy Notice** — Explains client-side data isolation.
2. **Step 2: Incident Intake** — Victims type, speak using **Web Speech recognition**, or select quick chips (*Threatened / Fake Profile / Photos Misused / Abusive Messages / Stalking / Panic*).
3. **Step 3: AI Understanding & Reassurance** — Delivers immediate reassurance (*"This is NOT your fault"*), explains criminal violations, and cites Indian statutory protections.
4. **Step 4: Emotional Check-in** — Asks how the victim feels (Scared, Sad, Ashamed, Angry, Action-ready) to tailor the response.
5. **Step 5: Free Mental Health Support** — Direct telephone triggers to KIRAN (`1800-599-0019`), Women Helpline (`181`), and Tele-MANAS.
6. **Step 6: Three Golden Safety Rules**:
   - *Rule 1*: Do NOT delete chat threads, SMS, or call logs (vital forensic evidence).
   - *Rule 2*: Do NOT negotiate or pay blackmailers (extortion never stops upon payment).
   - *Rule 3*: Call 112 or 181 immediately if physically threatened.
7. **Step 7: Proof & Evidence Vault** — Add attacker handles, phone numbers, and upload screenshots with **automatic image privacy blurring**.
8. **Step 8: Device Vault PIN** — Lock evidence behind a 4-digit PIN.
9. **Step 9: Formal Complaint Generation** — Auto-generated complaint draft with **Copy Text**, **Download .TXT**, and **Print / PDF Formal Letterhead Modal**.
10. **Step 10: Official Portal Direct Actions** — Direct links to `cybercrime.gov.in`, `1930`, and `StopNCII.org`.
11. **Step 11: Step-by-Step Portal Guide** — Live reference number tracker (`2026/CYBER/XXXXXX`).
12. **Step 12: Post-Reporting Emotional Grounding** — Compassionate validation and distress relief.
13. **Step 13: Cyber Safety Checklist** — 2FA app verification, third-party permission audit, and privacy lock.
14. **Step 14: Save Case or Clean Wipe** — Choose to create an ongoing account, exit without saving, or execute **"Wipe Traces & Exit"**.

## ⚖️ Statutory Protections Under Indian Law

| Section & Act | Crime Category | Penalty / Statutory Mandate |
| :--- | :--- | :--- |
| **Section 66E IT Act** | Violation of Bodily Privacy | Up to 3 years imprisonment + fine up to ₹2,00,000 |
| **Section 67 & 67A IT Act** | Obscene / Sexually Explicit Material | Up to 5 years imprisonment (1st offense) + non-bailable |
| **Section 354D IPC / Sec 78 BNS** | Cyberstalking & Online Surveillance | Up to 3 years imprisonment (up to 5 yrs on repeat) |
| **Section 506 IPC / Sec 351 BNS** | Criminal Intimidation & Blackmail | Up to 2 to 7 years imprisonment |
| **Rule 3(2)(b) IT Rules 2021** | 24-Hour Non-Consensual Imagery Takedown | Mandatory removal by Meta, Instagram, X within 24h |

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher)
- `npm` or `yarn`

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/ramadurai7886/cyber-buddy.git
cd cyber-buddy

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

The application will be running live at **http://localhost:3000**.

### Available Scripts
```bash
npm run dev        # Launch Vite development server on port 3000
npm run build      # Typecheck and build production bundle into /dist
npm run preview    # Preview production build locally
```

## 🔐 Privacy & Zero-Knowledge Security

- **Zero Server Tracking**: All personal intake, voice inputs, screenshots, and PINs remain strictly on the user's device.
- **Client-Side Image Auto-Blurring**: Protects against shoulder surfing and retraumatization.
- **Instant Anti-Surveillance Wipe**: 1-Click "Wipe Traces & Exit" clears all cache, case files, and auth tokens.
- **Discreet Weather / Calculator Camouflage**: Disguises the application when someone enters the room.
